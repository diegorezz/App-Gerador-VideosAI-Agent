# AI Video Agent v4 (Gratuito e Automatizado)

Aplicativo Streamlit para geração inteligente de vídeos para redes sociais a partir de um vídeo de referência e uma imagem base.

## O que há de novo na Versão 4:
1. **Sem Seleção Manual de Motores**: O sistema decide automaticamente o melhor motor disponível em código.
2. **Provedores de IA Amplos**: Configuração flexível (Automático, Google AI, Hugging Face, Modelos Locais).
3. **Interface Simplificada em 4 Passos**: Vídeo de referência + Imagem base + Chat inteligente + Geração automática.
4. **Espaço de Chat com o Agente**: Orientações adicionais opcionais aplicadas diretamente no roteiro e planejamento visual.
5. **Base de Conhecimento do Google Drive**: Integrado com a biblioteca de referência visual.
6. **Modo Gratuito Inteligente**: Renderização automatizada por FFmpeg e motores open-source/locais sem exigir APIs pagas.

## Como Executar:
- No Windows: Execute `INICIAR_APLICATIVO_WINDOWS.bat`
- No Mac/Linux: Execute `./INICIAR_APLICATIVO_MAC_LINUX.command`
- Ou via terminal: `streamlit run app.py`
